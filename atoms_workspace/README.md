# Atoms Agent Workspace

A dynamic, premium AI agent workspace for planning, approving, and generating interactive web applications, similar to `atoms-demo-steel.vercel.app`.

## Features
- **Interactive UI**: A chat-like interface to communicate with the AI agent.
- **Live Preview**: Generates HTML/JS/CSS directly and live renders it in a sandbox iframe.
- **Code View**: Inspect the code generated by the LLM.
- **Premium Aesthetics**: Dark mode, glassmorphism, responsive design.

## How to run locally

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Set your Google Gemini API Key:
   ```bash
   # Windows PowerShell
   $env:GEMINI_API_KEY="your_api_key_here"
   ```
3. Run the backend:
   ```bash
   uvicorn api.index:app --reload
   ```
4. Open `http://localhost:8000` in your browser.

## Deployment
This project is configured to be deployed on Vercel. 
Simply push to GitHub and import the project into Vercel. Make sure to set the `GEMINI_API_KEY` environment variable in Vercel settings.
